Privacy Policy

TheComputeClub Uploader · Last updated 31 October 2026

This policy covers the TheComputeClub Uploader (“the app”), a personal automation tool run by Aaditya Kaushik that uploads videos to the TheComputeClub YouTube channel.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the app

The app is used only by its owner, to manage the owner's own YouTube channel. It is not a public service, it has no sign-up, and it is not offered to other users.

What data the app accesses

  • An OAuth authorization token for the owner's own YouTube channel, with permission to upload videos.
  • Basic information about videos the app itself uploaded (for example video ID and upload status), used to confirm that an upload succeeded.

The app does not access, collect or store any data about other YouTube users, viewers, subscribers or commenters.

How data is used, stored and shared

  • The authorization token is used only to upload the owner's videos to the owner's channel.
  • It is stored as an encrypted secret in the owner's GitHub account and is never published or logged.
  • Upload results (video ID, title, date) are kept in a log in the owner's code repository.
  • No data is sold, shared with third parties, or used for advertising.

This website itself sets no cookies and uses no analytics or tracking.

Deleting data and revoking access

Access can be revoked at any time on the Google security settings page. When access is revoked, or on request, the stored token is deleted. Upload records can be deleted on request.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
